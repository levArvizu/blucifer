Construye una imagen con etiqueta fullstack-lab.

docker ps.

stop detiene, rm elimina.

docker exec -it <container> psql -U admin -d fullstacklab.

Ejecuta la imagen y expone el puerto 8080.

docker images.

docker logs = contenedor local, kubectl logs = pod en Kubernetes.

Muestra la configuración procesada de Compose.

docker restart backend-fullstack-lab.

docker --version = versión de Docker Engine, docker compose version = versión de Compose.
