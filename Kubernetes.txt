apply crea o actualiza, create solo crea.

-A = todos los namespaces, -n dev = solo el namespace dev.

kubectl rollout status deployment <nombre> o kubectl get pods.

kubectl logs <pod-name> o kubectl logs deployment/<nombre>.

ClusterIP = acceso interno, LoadBalancer = acceso externo.

kubectl rollout undo deployment <nombre>.

Simula la aplicación sin ejecutarla (valida sintaxis).

kubectl get all -n <namespace>.

kubectl create namespace test.

delete pod elimina un pod (se recrea si hay Deployment), delete deployment elimina todos los pods gestionados.
